# 💼 HR Management System

A web-based Human Resource Management System (HRMS) designed to streamline and automate human resource operations. The system provides administrators and HR personnel with tools to efficiently manage employees, departments, attendance, leave requests, payroll, and organizational records through a centralized platform.

---

## 📖 Overview

Managing employee information manually can be time-consuming and error-prone. This HR Management System digitizes HR processes, making employee management faster, more accurate, and more secure.

The application is suitable for small businesses, organizations, educational institutions, and enterprises seeking an efficient HR solution.

---

## ✨ Features

### 👥 Employee Management
- Add new employees
- Update employee information
- Delete employee records
- View employee profiles
- Employee search functionality

### 🏢 Department Management
- Create departments
- Assign employees to departments
- Manage department information

### 🕒 Attendance Management
- Daily attendance recording
- Attendance history
- Employee attendance reports

### 📝 Leave Management
- Leave request submission
- Leave approval and rejection
- Leave history tracking

### 💰 Payroll Management
- Employee salary records
- Payroll calculations
- Salary reports

### 🔐 User Authentication
- Secure login
- User registration
- Role-based access control
- Session management

### 📊 Dashboard
- Employee statistics
- Department summaries
- Attendance overview
- Leave summaries
